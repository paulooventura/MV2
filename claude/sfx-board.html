Synthesized voices — no file

These are generated live in js/sfx_posh.js + js/audio.js — there is no file to stream, which is why they had no play button. The board now loads the real audio engine, so ▶ calls sfx('name') and you can hear them. To replace one with a file: add name:'assets/SFX/name.wav' to SFX_SAMPLE_PATHS in js/audio.js and bump SFX_BUILD — the engine then prefers the file. (There is no automatic file-drop override.)

Replace a synth with a file — line generator

Type the voice name and your wav path. Copy the line into SFX_SAMPLE_PATHS in js/audio.js, bump SFX_BUILD, hard-refresh. The engine will then play your file instead of the generated voice.
